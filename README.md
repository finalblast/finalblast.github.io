## 👨‍💻 About Me

I'm Nick, a software engineer with 10 years in software development — 7 of them focused on web development, and 2 years building with AI tools such as Claude and Codex. I work across the whole stack and the infrastructure underneath it, from API and database design to deployment pipelines.

**Core skills**

- ⚡ **Currently focused on:** AI agents & LLM app development (Claude / OpenAI APIs, MCP, RAG, tool calling), AI-assisted engineering workflows, TypeScript + Next.js, serverless & edge (Cloudflare Workers, Vercel), React Native / Expo, SaaS product engineering (auth, billing, multi-tenancy)
- **Backend:** PHP (Laravel, Livewire, Lumen, Yii2), NodeJS, Python — REST APIs, queues, background jobs
- **Frontend:** VueJS, React / Next.js, TypeScript, AlpineJS, jQuery, TailwindCSS, Bootstrap
- **Data:** PostgreSQL, MySQL, MongoDB, SQLite, SQL Server, Redis — schema design, query tuning, reporting pipelines
- **Infra & DevOps:** Linux servers, AWS, Cloudflare, Docker, Nginx, CI/CD workflows, Git
- **Integrations:** social network & ad-platform APIs (Facebook, Google, Twitter, Bing, Taboola, Outbrain, Yahoo), payment gateways (Braintree, GoCardless), LDAP, SIP / VoIP telephony
- **AI-assisted development:** Claude, Codex, Copilot, CodeRabbit — 2 years shipping production code with them
- **Ways of working:** full software development lifecycle, Agile/Scrum, project management and team leadership
